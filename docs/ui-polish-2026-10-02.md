# Shared shell palette and control polish — 2 October 2026

The mobile dashboard now uses the desktop Marginalia palette at every width. Its mobile navigation, shelves, typography and reading layout remain intact. Uploaded cover assets and the reader's chosen page colors are unchanged.

## Color continuity

Shell color tokens live on `body:not(.reader-active)` rather than inside a desktop media query. Light and dark shells share the same paper, ink, sage accent, border and selected-surface values across breakpoints. Mobile progress bars, tab navigation, primary actions, secondary links and management surfaces use those tokens instead of hardcoded gold or brown. Safari/PWA chrome follows the actual shell paper color; the manifest launch background matches the default dark shell. Reader theme tokens remain independent.

## Dropdowns

All single-value selects gain a themed combobox and listbox. The original select remains the backing model for form submission, existing change handlers and programmatic updates. Native selects remain the fallback without the enhancement script; multi-select and list controls retain native behavior.

- Selected options show a checkmark; disabled options cannot be chosen.
- Arrow keys, Home/End and typeahead navigate. Enter or Space confirms; Escape cancels. Tab and outside interaction dismiss the popup.
- Dynamic voice lists, collection groups, asynchronous status rollback and disabled state stay synchronized.
- Popovers fit the visual viewport and flip above the trigger when needed. They work inside native dialogs and mobile sheets.
- Mouse selection preserves focus; touch handling preserves WebKit's synthesized click.
- Account, library tools and reader action menus gain consistent spacing and keyboard dismissal/navigation. Floating menus close when their anchor scrolls or the viewport changes.

## Motion plan

The authored moment is a 180 ms menu opening with a small translation and scale. Mobile sheets enter over 220 ms. Controls respond through 150 ms color and border changes; primary actions gain a subtle pressed inset. No entrance delays, repeating decorative animation, book-cover transformation or new page-turn animation are introduced. Reduced-motion preferences remove these menu and sheet animations and control transitions.

## Validation

Behavior coverage includes keyboard selection/cancellation, outside clicks, dynamic and disabled options, mobile/desktop light and dark palette continuity, reduced motion, menu focus, modal audio controls, browser touch taps at phone dimensions and long popup scrolling. The existing reader regression suite remains part of verification.

Visual inspection uses an isolated temporary database and fixture EPUBs, with desktop and phone captures in light and dark modes. The user's local library and accounts are not used for testing. Shell asset references and service-worker caches share version `v15.4.0-20261002`.
